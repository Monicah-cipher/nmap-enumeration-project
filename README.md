# Nmap Network Enumeration Project

## Overview
This project demonstrates basic network enumeration using Nmap on a TryHackMe lab environment. The goal was to identify open ports, running services, and possible attack surfaces.

## Tools Used
- Nmap
- Kali Linux
- TryHackMe

## What I Did
- Discovered live hosts
- Scanned open ports
- Identified running services and versions
- Analyzed potential vulnerabilities

## Key Takeaways
- Importance of proper network enumeration
- Understanding service exposure
- How attackers gather initial information

## Disclaimer
This project was performed in a controlled lab environment for learning purposes only.
